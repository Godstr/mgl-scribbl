# skribbl.io — монгол хувилбар

Олон тоглогчтой зурж таах тоглоом (skribbl.io), бүхэлдээ монгол хэл дээр.

## Ажиллуулах

```bash
npm install
npm start
```

Дараа нь хөтөч дээр **http://localhost:3000** нээнэ.
Нэг Wi-Fi-д холбогдсон найзууд терминал дээр гарах `http://192.168.x.x:3000` хаягаар нэгдэнэ
(хувийн өрөөний «Урих» товч энэ хаягийг автоматаар хуулна).

Портыг өөрчлөх: `PORT=8080 npm start`

## Онцлогууд

- Нийтийн өрөө (16 хүн хүртэл, автоматаар эхэлнэ) ба хувийн өрөө (20 хүн хүртэл)
- Өрөөний тохиргоо: тоглогчийн тоо, зурах хугацаа, үе, үгийн тоо, зөвлөмж, өөрийн үгс
- 700 гаруй монгол үг
- Латинаар бичсэн таамгийг ч ойлгоно: `nohoi` = `нохой`, `vher` = `үхэр`
- «Ойрхон байна!» сануулга, үсэг илрүүлэх зөвлөмж
- 26 өнгө, 5 хэмжээ, бийр, будах, буцаах, арилгах; товчлол B / F / U / C / 1–5
- Аватар тохируулах, санал өгч хасах, дуугүй болгох, эзэн хасах/хориглох, таалагдлаа/үгүй
- Гар утас, таблетад тохирсон
